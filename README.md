# Booking API

REST API для онлайн-бронирования столиков в ресторане

Технологии

- Python 3.11+
- FastAPI
- Pydantic v2
- SQLAlchemy 2.0
- SQLite
- Pytest

Запуск

1. Клонируйте репозиторий и перейди в папку проекта:
   git clone <url>
   cd mise_booking
2. Создайте и активируйте виртуальное окружение:

python -m venv venv
Windows: venv\Scripts\activate

3. Установите зависимости:

pip install -r requirements.txt

4. Запустите сервер:
python main.py

5. Откройте документацию:

Swagger: http://127.0.0.1:8000/docs

ReDoc: http://127.0.0.1:8000/redoc

# Эндпоинты

POST /booking Создать брон
GET /booking Список броней (фильтр по дате)
GET	/booking/{id} Получить бронь по id
DELETE /booking/{id} Отменить бронь

# Валидация
Все поля проверяются через Pydantic:
Имя: минимум 2 символа, только буквы, пробелы и дефис
Телефон: российский формат (+7 или 8 + 10 цифр)
Дата: от сегодня до +90 дней
Время: 12:00–22:00, только часы
Гости: от 1 до 12

# Тесты
Запустите тесты командой:

pytest tests/ -v

# Решения
Использовал SQLite для упрощения развёртывания и визуализации данных без внешней БД
Разделил код на слои: роуты, сервисы, схемы и модели - для удобного поиска и поддержки
Реализовал проверку пересечения слотов, чтобы два гостя не забронировали одно время
Обработал ошибки с понятными статус кодами и сообщениями
